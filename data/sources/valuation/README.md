# 相对市盈率锚点（`docs/data/valuation.json` 的输入）

| 文件 | 内容 |
|---|---|
| `relative_pe_inputs.json` | 锚点原值 `M_raw`、彭博标签、1985 区间、来源与层级说明 |
| `fred_NASDAQ100_2026-08-25_2026-09-12.csv`、`fred_SP500_2026-08-25_2026-09-12.csv` | 2026-09-12 下载的 FRED `fredgraph.csv` 原文件 |

**定义.** `M = 纳指100 市盈率 ÷ 标普500 市盈率`（彭博 PE_RATIO 口径）；`R = 纳指100/标普500 价格比`；相对EPS = `R ÷ M`。

**`bbg_chart`（实测·彭博）.** 用户彭博相对市盈率图截图的季末读数（研究 c3 提取，与图上标签相差 0.3% 以内）。只发布 2004-12、2014-12、2024-12 三个比值。

**`bridge`（估算）.** BetaShares 2016 顾问材料中的 NDX 市盈率图（矢量提取，数据 Bloomberg/Thomson Reuters）÷ Shiller 标普500 as-reported 市盈率。
- `alignment: "shift"`：图上标注为 m+1 月 1 日的点对应 m 月末。
- 口径平移：`M = M_raw × e^0.14`。0.14 为 2003—2015 重叠期（剔除危机季度）桥接值低于彭博口径的对数差；2004-12 单点差 0.143。季度变化与彭博相关性仅 0.13—0.18，因此只作水平锚点，不作路径。
- `m0_1985.central` = 平移后的 1985-01 锚点；`low/high` 1.8/2.5 为研究 c3 在彭博口径下的 p10—p90。
- 该材料标注不得分发，仓库只保存三个推导比值，不保存其市盈率数值。

**`bbg_label` 与 `latest`.** 2026-09-10 彭博标签 37.05 ÷ 26.18 = 1.4152。`build_data.py` 把它调整到数据月末：`M = M_label × R(月末) ÷ R(标签日)`，`R(月末)` 用本站月末点位（先核对 FRED 月末收盘相差不超过 0.005），`R(标签日)` 用 FRED 收盘；假设两日之间 TTM EPS 不变。无法核实时 `M = M_label`，并在 `adj` 中写明。

**链式检查.** 十年分段（d1985…d2025）与全期（起点 `m0_1985.central`）的价格项逐段相加完全闭合；市盈率/EPS 项只在 2004-12 桥接→彭博处有拼接差。`build_data.py` 打印该差值并断言不超过 2 个对数点，`tests/data.test.js` 复核。

**许可.** 只发布少量推导比值与两枚市盈率标签，不发布任何月度供应商序列。
