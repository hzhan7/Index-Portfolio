## 方法

### 指标

- 收益行从起点的下一个月开始（起点月末净值 = 1）。组合固定权重、每月末再平衡、美元、不计成本。
- 年化复合收益 `exp(12·mean ln(1+r)) − 1`；年化波动 `√12·std(r)`；夏普 `√12·mean(r − rf) / std(r − rf)`（ddof = 1；rf = 同月1个月国库券；不足12个月不计）。
- 最大回撤：月末净值相对此前高点；回本月数 = 谷底 → 回到前高。最差12个月：滚动12个月复合收益最小值。
- 跟踪误差 `√12·std(r_p − r_标普)`；信息比率 `12·mean(r_p − r_标普) / 跟踪误差`。
- 均值方差输入 `μ = 12·mean(r)`（算术）、`Σ = 12·cov(r)`；模型波动/跟踪误差与同月份路径值一致到 1e-12。
- 降到标普波动：`a = std(标普超额) / std(纳指超额)`，`r = a·r_纳指 + (1 − a)·rf`。α/β：纳指超额对标普超额 OLS，Newey-West（Bartlett 12阶，无自由度修正）。
- 夏普差95%区间：环形块自助法 1000 次，块长 24 个月（样本不足 96 个月时取 ⌊n/4⌋），种子 20260912，type-7 分位。
- 股息预扣税 t：股票月收益减 `t·(含息 − 价格)`。价格口径的夏普仍相对国库券计算。

### 配置规则（§3 页签）

1. **同波动·收益最高**（默认）：`max μ′w`，约束 `w′Σw ≤ (m·σ_标普)²`、`(w − e_标普)′Σ(w − e_标普) ≤ k²`、`w ≥ 0`、`Σw = 1`；默认 m = 1、k = 5%。
   - 求解：精确活跃集枚举，候选为 3 个顶点、各椭圆约束的平面内最优点、椭圆 ∩ 单纯形边、两椭圆交点，不走迭代。
   - 同时输出 k 不限的纯同波动点、k 路径与平顶、μ_纳指 −1/−2 个百分点后的权重。
   - 无解时给出当前 m 下的最小可行 k。
2. **收益≥标普·夏普最高**：`max 夏普(路径)`，约束 `年化复合收益 ≥ 标普500`、`w ≥ 0`。按纳指权重 128 步外层扫描 + 黄金分割细化；给定纳指权重时，夏普驻点与等式根解析求解。确定性数值搜索。
3. **切点组合**：`max (μ′w − c) / √(w′Σw)`，`w ≥ 0`，单纯形 7 个面精确枚举。截距 c 可选：同波动隐含截距 c*（默认）｜无风险利率（样本 RF 年化均值）｜10年美债（样本末 DGS10 按 `(1+y/2)² − 1` 换算）｜自定义（0～20%）。
   - 隐含截距：纯同波动点的持仓资产满足 `μ_i − c = γ(Σw)_i`（γ > 0；未持仓资产 `μ_j − c ≤ γ(Σw)_j`），c* 使切点恰好落在该点。`c* = RF + 不能加杠杆的影子成本`（默认样本 5.69% = 3.16% + 2.53个百分点）。
   - 截距 → 权重路径：c 步长 0.05%，二分求 美债 < 50%、美债 = 0、纳指 = 100% 的阈值。
   - 杠杆（折线资本市场线）：借入利率 `RF + 利差`（0 / 0.5% / 1%），贷出利率 `RF`，目标波动 `m·σ_标普`。
     - 目标 ≥ 借款切点波动：加杠杆，`L = 目标 / σ`。
     - 目标 ≤ 贷出切点波动：去杠杆。
     - 介于两者之间：取有效前沿上该波动的点。
     - 月收益 `L·r_切点 − (L − 1)·rf − max(L − 1, 0)·利差/12`。
4. **纳指+美债**（也可选 标普+美债、纳指+标普）：x = 第一个资产权重，画 1001 点曲线。
   - 夏普 = 标普500：解 `12(a + bx)² = S²(c0 + c1·x + c2·x²)`（超额收益矩，要求 a + bx > 0）。
   - 波动 = 标普500：解二次方程。
   - 年化 = 标普500：在凹函数 `g(x) = mean ln(1 + r_j + x(r_i − r_j))` 峰值两侧二分。
   - 「你问过的组合」取最大的夏普根。
5. **自定义**：整数权重合计 100，另选补足项。

### 稳健性（§4）

- **重抽样**：环形块自助法，块长 24 个月（样本不足 96 个月时取 ⌊n/4⌋）；第 b 次抽样种子 `(20260912 ^ imul(b+1, 0x9E3779B1)) >>> 0`，mulberry32。
  - 资产与 RF 用同一组索引；每次重算 σ_标普、RF 与标普年化，10年美债收益率保持样本末值。
  - 切点规则与样本外一致，抽的是杠杆线组合（借入 RF + 利差，目标波动 m·σ_标普），与截距设置无关：分位为风险资产权重，另报杠杆倍数与名义权重分位。
  - 次数：同波动 1000、切点 1000、收益≥标普 200。
  - 报告 p10/p50/p90，以及美债 > 50%、标普 < 1%、单一资产 ≥ 99% 的概率。
- **样本外（walk-forward）**：再平衡月 = 样本首个收益月及此后每年1月。
  - 估计窗 = 该月之前 120 个收益月（过去10年），或 1985-02 起全部历史；取自全数据，不受样本起点限制；不足 120 个月的年份跳过。
  - σ_标普 上限、RF、标普年化下限、DGS10 都取自估计窗。
  - 权重持有到下一次重估，期间每月再平衡；切点规则用杠杆线。
  - 样本外不足 36 个月不报告。
  - 对照「样本内静态（含未来信息）」：在样本外月份上估计，并在同一段评估。
- Python 端逐位移植 RNG，重抽样分位与 walk-forward 权重核对到 1e-9。

### 估值 vs EPS（§2）

- 恒等式：R = 纳指100/标普500 价格点位比，M = 相对市盈率，E = R/M，则 `Δln R = Δln M + Δln E`。含息总回报差 = `Δln R + D`，其中 `D = Δln(含息/价格)_纳指 − Δln(含息/价格)_标普`，随含息口径、股息档与预扣税变化。
- 单位：个百分点/年（对数口径）= `100·Δln / 年数`。同一行内各项可直接相加：价格差 = 估值 + EPS，总回报差 = 价格差 + 股息。各区间年数不同，年化值不能跨区间直接相加；要先乘年数还原成对数点（`100·Δln`），对数点可跨相邻区间相加，十年分段合计与全期之差即口径拼接差。只有 `|Δln| ≥ 0.10` 且 `|年化| ≥ 1` 时才给出占比。
- 锚点月份：1985-01、1994-12、2004-12、2014-12、2024-12、2026-08，R 取月末点位。1985-01 的 M 默认 2.014；滑块 0.50～4.00 同时改第一段与全期。
- 盈亏平衡：估值占价格差 s 时，所需 1985-01 相对市盈率 `M0 = M_2026-08 · exp(−s·Δln R)`；s = 0 时 M0 = 1.415。
- **彭博导入**（§2「用你的彭博数据重算」）：文件只在浏览器本地解析，不上传。
  - Excel 分块模板，每块 3 行：证券名、字段代码、公式。例：`=BDH("NDX Index","PE_RATIO","19850101","<数据月末 yyyymmdd>","period=cm")`；同样取 `PX_LAST`，SPX Index 同理。
  - 可选字段：`XNDX Index` / `SPXT Index` 的 `PX_LAST`（股息项），`T12_EPS_AGGTE`（闭合检验），`BEST_PE_RATIO`（预期市盈率，单独成组）。字段先在 `FLDS <GO>` 核实。
  - 也可用宽表 CSV：必填 `date, ndx_px, spx_px, ndx_pe, spx_pe`，可选 `ndx_eps, spx_eps, ndx_tr, spx_tr, ndx_pe_fwd, spx_pe_fwd`。
  - 输出按十年分段；PE_RATIO 起点晚于 1985 时给出部分样本与 1985 敏感性。

## 局限

1. 纳指100 1985-02～1999-03 股息为估算；低/高档下纳指年化 14.72%～14.81%。
2. 标普500 1985-02～1988-01 含息为构建序列；1988-02 起 SPXTR 取自 Yahoo 月末二手快照。
3. 10年美债是 DGS10 平价债模型收益，不含曲线滚降与实际付息日，不对应可交易基金。
4. 1985-01、1994-12、2004-12 相对市盈率为第三方图表 ÷ Shiller 的桥接估算；1985-01 区间 1.8～2.5。
5. 不计交易成本、管理费和税；股息预扣税可选 0/15/30%，杠杆只计 RF + 利差。
6. 月末数据：回撤、波动、最差12个月均按月末计，日度回撤更深。
7. 均值方差权重对预期收益敏感（纳指 μ 少 1个百分点：纳指 39% → 26%）；样本外只有一条历史路径、31 次年度重估。
8. 2026-08 RF 为暂估；数据静态截至 2026-08，不自动更新。
